The Townsend cooling integrator

Radiative cooling is the stiffest source term in simulations of galaxies and clusters. Around $10^5$ K the gas can cool in a time that is orders of magnitude shorter than the hydrodynamical timestep, and an ordinary explicit update then overshoots, or forces the code to take tiny substeps. Townsend (2009) noticed that if the cooling curve is a piecewise power law, the cooling equation can be integrated exactly, in a single evaluation per cell, for any timestep.

This short page shows how. The two figures are interactive. It is the scheme behind the townsend option of AthenaPK's tabular cooling.

The problem: a stiff ordinary equation

In an operator-split code the cooling is applied after the hydrodynamical update, cell by cell, with the density held fixed during the step. With hydrogen number density $n_{\rm H}$, the specific internal energy $e$ obeys $\rho\,\dot e=-n_{\rm H}^2\Lambda(T)$, and since $T=(\gamma-1)\,\bar m\,e/k_B$ this is an ordinary differential equation for the temperature alone:

\frac{\mathrm{d}T}{\mathrm{d}t}=-\mathcal{K}\,\Lambda(T),\qquad \mathcal{K}=\frac{(\gamma-1)\,\bar m}{k_B}\,\frac{n_{\rm H}^2}{\rho}

Here $\Lambda(T)$ is the cooling function tabulated from atomic physics, and $\mathcal K$ is a constant for the step. The local cooling time is $t_{\rm cool}=T/(\mathcal K\Lambda)$. The difficulty is that $\Lambda$ changes by two orders of magnitude between $10^4$ and $2\times10^5$ K: a cell that cools slowly at the start of the step can become a runaway a fraction of a step later. A forward-Euler update uses the cooling rate at the start of the step, so it either subcycles at a cost, or, when $\Delta t$ approaches $t_{\rm cool}$, it takes the gas too far down the curve.

A clock that runs in temperature

The equation separates, $\mathrm dT/\Lambda(T)=-\mathcal K\,\mathrm dt$. Pick a reference temperature $T_{\rm ref}$ (the top of the table) and define the temporal evolution function

Y(T)=\frac{\Lambda_{\rm ref}}{T_{\rm ref}}\int_{T}^{T_{\rm ref}}\frac{\mathrm{d}T'}{\Lambda(T')}

$Y(T)$ is the time the gas needs to cool from $T_{\rm ref}$ down to $T$, measured in units of the cooling time at the reference, $t_{\rm ref}=T_{\rm ref}/(\mathcal K\Lambda_{\rm ref})$. It decreases monotonically with $T$, so it can be inverted. And because the equation is autonomous, evolving the gas for a time $\Delta t$ simply moves its position on this clock forward by $\Delta t$:

Y(T_{\rm new})=Y(T_{\rm old})+\frac{\Delta t}{t_{\rm ref}}

No iteration is needed provided $Y$ and its inverse $Y^{-1}$ are known in closed form. That is where the piecewise power law comes in. Tabulate $\Lambda$ at temperatures $T_0<T_1<\dots<T_N$ and interpolate linearly in log-log, so that in each bin

\Lambda(T)=\Lambda_k\left(\frac{T}{T_k}\right)^{\alpha_k},\qquad \alpha_k=\frac{\ln(\Lambda_{k+1}/\Lambda_k)}{\ln(T_{k+1}/T_k)},\qquad T_k\le T<T_{k+1}

The integral is then elementary. Writing $Y_k\equiv Y(T_k)$, which is accumulated once at start-up from the top of the table downwards, one has for $T$ in bin $k$

Y(T)=Y_k+\frac{1}{1-\alpha_k}\,\frac{\Lambda_{\rm ref}}{\Lambda_k}\,\frac{T_k}{T_{\rm ref}}\left[1-\left(\frac{T_k}{T}\right)^{\alpha_k-1}\right]

and, solving for $T$ in the bin that contains the new value $Y^\ast$,

Y^{-1}(Y^\ast)=T_k\left[1-(1-\alpha_k)\,\frac{\Lambda_k}{\Lambda_{\rm ref}}\,\frac{T_{\rm ref}}{T_k}\,\bigl(Y^\ast-Y_k\bigr)\right]^{1/(1-\alpha_k)}

What is computed once, at start-up

Everything above that depends only on the cooling table, and not on the state of any cell, is prepared before the first timestep. The table is a plain text file with two numbers per line, $\log_{10}T$ in K and $\log_{10}\Lambda$ in ${\rm erg\,cm^3\,s^{-1}}$, with increasing temperature. The code converts $\Lambda$ to code units and then builds three arrays, which are copied once to the device and only read afterwards:

  1. The knots $T_k$ and $\Lambda_k$ for $k=0,\dots,N$, in linear (not logarithmic) form. The last row is the reference, $T_{\rm ref}=T_N$ and $\Lambda_{\rm ref}=\Lambda_N$.
  2. The slopes $\alpha_k$, one per bin ($N$ values for $N+1$ knots), from the log-log slope between neighbouring rows.
  3. The clock values $Y_k=Y(T_k)$, accumulated from the top of the table downwards with the same closed form as before, applied from one knot to the next:
Y_k=Y_{k+1}+\frac{1}{1-\alpha_k}\,\frac{\Lambda_{\rm ref}}{\Lambda_k}\,\frac{T_k}{T_{\rm ref}}\left[\left(\frac{T_k}{T_{k+1}}\right)^{\alpha_k-1}-1\right],\qquad Y_N=0

(AthenaPK puts the zero of the clock at the lower knot of the last bin instead of at the top knot. That shifts every $Y$ by the same constant and changes nothing, since only differences of $Y$ are ever used.) After this, a step needs only the bin search and two power laws. The one quantity that depends on the cell, $\mathcal K\propto n_{\rm H}^2/\rho$, is a single multiplication at run time. The whole set-up is a loop over the rows of the table, so its cost is negligible and its memory is a few numbers per row, shared by every cell.

The schematic 17-row table used in the figures (a real table has its own spacing and a different number of rows). The last row has no bin above it, so it has no slope, and $Y_N=0$ by construction. $Y_k$ barely changes below $10^7$ K: the reference time $t_{\rm ref}$ is the cooling time of the hottest gas, which is far longer than at any lower temperature, so almost all of the clock is spent in the last few bins. The figure below therefore plots the time left instead. When you move the sliders there, the bin holding $T_{\rm old}$ is highlighted in blue here and the bin holding $T_{\rm new}$ in orange.

One step, in four moves

  1. Find the bin of the current temperature $T_{\rm old}$ and evaluate $Y(T_{\rm old})$ from the first formula.
  2. Advance the clock: $Y^\ast=Y(T_{\rm old})+\Delta t/t_{\rm ref}$.
  3. Find the new bin. $Y$ grows as the gas cools, so this is a short walk down the table from the old bin. It may cross many bins, and that costs nothing extra.
  4. Invert with the second formula to get $T_{\rm new}$, and put the corresponding energy back into the cell.

What it buys, and what it does not

PropertyComment
CostOne bin search and two power laws per cell, whatever $\Delta t$. There is no iteration and no subcycling: every cell takes the same short path.
AccuracyExact for the tabulated $\Lambda$ read as a piecewise power law. The remaining error is that of the interpolation (a finer table helps), and the first-order error of splitting the cooling from the hydrodynamics.
StabilityUnconditional: the gas is carried down the cooling curve and never overshoots, however large $\Delta t$ is. It cannot go below the bottom of the table.
HeatingNot included. The ODE must depend on $T$ only through $\Lambda$, so a heating term that does not scale like cooling has to be applied separately, or folded into a net cooling curve.
Fixed density$\mathcal K$ is constant during the step. That is the usual operator-splitting assumption, and it is exact for a cell that cools isochorically.
Special caseA bin with slope exactly $\alpha_k=1$ turns the power into a logarithm in both formulas. AthenaPK does not implement that case and refuses such a table.
TimestepThe integrator does not need a cooling timestep limit, but AthenaPK can still cap the step at a fraction of the shortest cooling time (a cooling CFL) so that cooling and hydrodynamics stay coupled.

In AthenaPK the table is read at start-up, converted to code units, and the slopes $\alpha_k$ and the values $Y_k$ are computed once. During the run a cell below the temperature floor is reset to the floor, and a cell below the first table temperature is left alone: it does not cool at all, rather than cooling with an extrapolated curve.
